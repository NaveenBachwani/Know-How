# Bash Commands

## Current directory

```bash
pwd
```

---

## List files

```bash
ll
```

---

## Hidden files

```bash
ls -la
```

---

## Create folder

```bash
mkdir folder-name
```

---

## Remove folder

```bash
rm -rf folder-name
```

---

## Search history

```bash
history
```

```bash
history | grep git
```

---

## Clear screen

```bash
clear
```
