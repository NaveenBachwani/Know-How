# Python Virtual Environments

## Create

```bash
python3 -m venv venv
```

---

## Activate

```bash
source venv/bin/activate
```

---

## Deactivate

```bash
deactivate
```

---

## Install packages

```bash
pip install package-name
```

---

## Freeze requirements

```bash
pip freeze > requirements.txt
```

---

## Install requirements

```bash
pip install -r requirements.txt
```
